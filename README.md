# NTNSP ONE Portal — V3

GitHub-ready NTNSP / CEATP-I digital workplace prototype.

## Deploy
1. Create a GitHub repository, e.g. `NTNSP-ONE-Portal`.
2. Upload the contents of this folder.
3. Keep `index.html` at repository root.
4. GitHub: Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
5. Open the GitHub Pages URL.

## Important
This is a front-end V3 prototype. Do not put confidential production data into it. Login is a demo only. V4 should connect secure authentication, role permissions, PostgreSQL/API, storage, audit logs and reports.
