# NTNSP ONE V3 Architecture

V3 is a GitHub Pages-ready front-end prototype.

## Modules
Dashboard, HR, Wayleave, Fleet/Fuel, Inventory, Fixed Assets/BOS, Procurement/TEC/BEC, Finance, AI Office, Documents and Administration.

## Wayleave target model
Transmission Line → Tower → Span → Parcel → Owner/Occupier → Trees → Valuation → Compensation → Payment → Documents/Photos.

## Production V4
Frontend → secure authentication/roles → API → PostgreSQL → document storage → audit trail → reports.

The V3 browser localStorage is only for demonstration. It is not a secure multi-user database.
